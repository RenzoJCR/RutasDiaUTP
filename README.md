# Rutas Día UTP

Sistema web para la gestión de eventos Día UTP de UTP Lima Norte.

## Objetivo

Digitalizar y mejorar la gestión de:

- eventos Día UTP;
- mentores;
- alumnos y asistencia;
- buses;
- grupos de recorrido;
- laboratorios;
- incidencias;
- recorridos dinámicos en tiempo real;
- reportes e históricos.

## Arquitectura

El proyecto está dividido en servicios independientes:

- `backend/`: Spring Boot + Java
- `frontend/`: React + Vite
- `infra/`: infraestructura local y despliegue
- `docs/`: documentación del proyecto

## Tecnologías principales

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- WebSocket + STOMP
- MySQL
- Maven

### Frontend
- React
- Vite
- Bootstrap
- Axios
- STOMP.js

### Infraestructura
- Docker
- Docker Compose
- Azure
- GitHub
